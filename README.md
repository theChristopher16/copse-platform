## Vision
Multi-tenant SaaS platform supporting:
- **Scouts** (Cub Scouts, Boy Scouts, etc.)
- **Sports** (Youth leagues, clubs, teams)
- **Schools** (K-12, universities, districts)
- **Businesses** (SMB to enterprise)
- **ICS/OT** (Industrial Control Systems/Operational Technology)

## Architecture
- **Tenant-scoped data isolation**
- **Role-based access control (RBAC)**
- **Organization-specific feature sets**
- **Enterprise-grade security**
- **Scalable multi-region deployment**
